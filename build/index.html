Behind the build

Clean work you won’t see, but will rely on.

The parts that keep money right, messages sent once and every change traceable. Each one below is running in a real build today.

  • The server sets the price

    The browser never decides what a customer pays. Every cart is repriced on the server before checkout.

    Miniature Bookshop · Next.js 16 · Postgres on Neon

  • Emails go out exactly once

    Each order claims its email. If a send fails, the claim is given back so it can go again. Nobody gets two receipts, or none.

    Miniature Bookshop · order and gift emails

  • A person approves every send

    The AI drafts. Nothing reaches a prospect until someone has read it and pressed send.

    AegisLeadOS · human-gated outreach

  • Tested before it ships

    1,231 automated tests on AegisLeadOS. A 92-check test walks the Bookshop’s whole purchase on a phone-sized screen.

    AegisLeadOS · Miniature Bookshop

  • Fast where it counts

    Tap redirects run at the edge, close to the customer. Bot taps are flagged and a double tap within 10 seconds counts once.

    Tapfour · Cloudflare Workers · D1

  • Numbers you can trust

    No made-up figures. Every insight is labelled by how much data is behind it, developing or reliable.

    Trader Journal · Node 22 · PostgreSQL
