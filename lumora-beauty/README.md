# Lumora Beauty

Concept store for **Lumora Beauty**, a health and beauty brand, designed by Chester Studio for the
Minimog Shopify theme: brand identity, product imagery, homepage and product page.

Work in progress. Not linked from the live site.

| Folder | Contents |
|---|---|
| `research/` | Notes on reference stores, a Minimog capability map, a beauty DTC playbook |
| `brand/` | Brand concepts, brand book, logo files |
| `renders/` | Blender (Cycles) rig for packshots and still-life scenes, render jobs, finished renders |
| `products/` | The six product images and product sheet |
| `photos/` | Colour-graded editorial photography and credits |
| `mockup/` | Homepage and product page mockups (source and exported PNGs) |
| `build/` | Minimog build guide, copy deck, section settings, custom CSS |
