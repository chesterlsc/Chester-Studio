# Agent briefs (templates for the chapter loop)

Loop per chapter: **research → write + visuals (parallel) → fact-check → polish → PROGRESS → commit**.
Each agent gets only its chapter's TOC entry + STYLE.md (+ COMPONENTS.md for writers/visual makers).
Replace `{N}`, `{NN}`, `{TITLE}`, `{PAGES}`, `{SLUG}` before use.

## 1. Research
> You are the RESEARCH agent for Chapter {N} "{TITLE}" of OFFGRID 30 (survival book, ages 10–80, 30 years without power). Read `offgrid-30/docs/STYLE.md` §2 first (facts only, Tier 1–3 sources, never fill gaps from memory). Pages: {PAGES}. For every page, collect the facts a reader needs (numbers, steps, materials, warnings, legal notes), verified on the source page itself. Write `offgrid-30/docs/research/ch{NN}-facts.md` with: 1) Sources table (id, org, exact title, date on page, final URL, checked date, tier); 2) Facts by page (plain fact → "short exact quote" → [id]; both units, mark conversions [conv]); 3) Conflicts (both sides + safer choice); 4) Not verified / not found. Also suggest 1–2 main-visual ideas per page (what the diagram should show) and mark pages where 3D truly helps understanding. Keep quotes short; paraphrase copyrighted text. Allowed hosts include CDC, WHO (+iris/cdn/apps), Ready.gov, FEMA, EPA, FDA, USDA (+NAL/ARS/NRCS/FS/FSIS), NCHFP, Red Cross, MedlinePlus, NHS, PMC/PubMed, National Academies, Sphere, armypubs.army.mil, extension (PSU, NDSU, UMN, OSU, CSU, USU), AVMA, ASPCA, NREL, DOE, ARRL, FCC, NFPA, USFA, OSHA, USGS, NCCIH, ODS, NIA, NIMH, SAMHSA, 988, HealthyChildren (AAP), ACOG, IFRC, Cochrane, FWS, NPS, Wikimedia Commons, weather.gov, UNICEF, foodsafety.gov. Edit no other file. Finish with a short summary (facts, sources, gaps).

## 2. Writer
> You are the WRITER for Chapter {N}. Read STYLE.md, COMPONENTS.md, the reference page 4.3 and Chapter 1 pages (`src/content/pages/01-water-basics-how-much-you-need/`) for tone, then `docs/research/ch{NN}-facts.md` (the ONLY allowed facts). Write 10 MDX files in `src/content/pages/{SLUG}/` (names from `src/data/toc.json`). Diagrams are drawn in parallel by other agents at `src/components/diagrams/ch{NN}/<Name>.astro` per the visual spec below — import them, don't create them. Verify with `npx astro build --outDir <scratch dir>` (never into the shared dist). Report word counts and anything uncertain.

## 3. Visuals (split into 2 agents of ~5 diagrams)
> You are a VISUAL DESIGNER for Chapter {N}. Read STYLE.md §5–6, COMPONENTS.md "Diagram rules", `src/components/diagrams/ch04/BoilMain.astro` and the ch01 diagrams for style, `src/styles/tokens.css`, and `docs/research/ch{NN}-facts.md` (only source for label text). Make: {LIST WITH SPECS}. Preview via a temporary page `src/pages/preview-ch{NN}x.astro` (no leading underscore), build with `--outDir` to a scratch folder, screenshot at 390px light + dark with Playwright, Read the PNGs, fix, then delete the preview page. 3D models (only where the plan marks [3D]): `src/components/three/models/<Name>.tsx` + `<name>.meta.ts` steps + register in `Viewer.tsx`, with the 2D diagram as fallback.

## 4. Fact-check
> You are the independent FACT-CHECKER for Chapter {N}. Read STYLE.md §2, 3, 7. Check every claim in `src/content/pages/{SLUG}/*.mdx` and the text in `src/components/diagrams/ch{NN}/*.astro` against the research notes AND the live source pages. Check unit conversions, quiz answers, references, red-flag grading, child safety. Write `docs/research/ch{NN}-factcheck.md` (verdict, issues table with severity + exact fix, verified list, unreachable sources). Do not edit pages.
